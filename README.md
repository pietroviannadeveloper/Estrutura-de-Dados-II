
# Estrutura de Dados II

Repositório destinado às atividades e exercícios desenvolvidos na disciplina de **Estrutura de Dados II**.

O objetivo é reunir implementações práticas de algoritmos e estruturas de dados, acompanhadas de testes e análises de complexidade.

## Conteúdos estudados

* Arrays e matrizes
* Busca sequencial
* Bubble Sort
* Quick Sort
* Índices e percursos
* Loops simples e aninhados
* Comparação entre algoritmos
* Complexidade computacional
* Análise de operações

## Tecnologias utilizadas

* Python 3
* Jupyter Notebook
* Google Colab / JupyterLab
* Visual Studio Code

## Organização

Os códigos estão organizados em notebooks com explicações curtas sobre:

* o que cada algoritmo faz;
* qual o objetivo da implementação;
* como ele funciona;
* qual sua complexidade;
* quais resultados foram obtidos nos testes.

## Complexidades principais

| Algoritmo / Operação | Complexidade          |
| -------------------- | --------------------- |
| Percurso em array    | `O(n)`                |
| Busca em matriz      | `O(m × n)`            |
| Bubble Sort          | `O(n²)`               |
| Quick Sort           | `O(n log n)` em média |

## Objetivo

Aplicar na prática os conceitos estudados em Estrutura de Dados II e compreender como a escolha de uma estrutura ou algoritmo pode afetar o desempenho de um programa.
